# CodeRabbit Setup Guide для Gangsters: Real City

## Что такое CodeRabbit?

CodeRabbit - это AI-ассистент для code review, который автоматически анализирует ваш код и предлагает улучшения. Он особенно полезен для игровых проектов, так как понимает специфику игрового кода.

## Пошаговая настройка

### Шаг 1: Установка GitHub App

1. Перейдите на [coderabbit.ai](https://coderabbit.ai)
2. Нажмите "Install GitHub App"
3. Войдите в свой GitHub аккаунт
4. Выберите репозиторий `gangsters-real-city`
5. Настройте права доступа:
   - ✅ Repository contents: Read
   - ✅ Pull requests: Write
   - ✅ Issues: Write
   - ✅ Metadata: Read

### Шаг 2: Проверка файлов конфигурации

Убедитесь, что в репозитории есть следующие файлы:

```bash
# Основной конфигурационный файл
.coderabbit.yaml

# GitHub Actions workflow
.github/workflows/coderabbit.yml

# Файл владельцев кода
.github/CODEOWNERS
```

### Шаг 3: Настройка переменных окружения (опционально)

В настройках репозитория GitHub:
1. Перейдите в Settings > Secrets and variables > Actions
2. Добавьте следующие секреты:

```
CODERABBIT_API_KEY=your_api_key_here
YANDEX_MAPS_API_KEY=your_yandex_maps_key_here
```

### Шаг 4: Тестирование

1. Создайте тестовую ветку:
```bash
git checkout -b test-coderabbit
```

2. Внесите небольшое изменение в код:
```bash
echo "// Тестовый комментарий для CodeRabbit" >> game.js
```

3. Создайте коммит и push:
```bash
git add .
git commit -m "Test CodeRabbit integration"
git push origin test-coderabbit
```

4. Создайте Pull Request и проверьте работу CodeRabbit

## Возможности CodeRabbit для вашего проекта

### 🎮 Анализ игрового кода

CodeRabbit специально настроен для анализа игрового кода и понимает:

- **Игровые механики**: Баланс, логика, правила
- **Производительность**: Оптимизация игрового цикла
- **Безопасность**: Защита игровых данных
- **Геолокация**: Корректность работы с координатами

### 🗺️ Специальные проверки для Яндекс.Карт

- Правильность использования API
- Обработка ошибок геолокации
- Оптимизация загрузки карт
- Безопасность API ключей

### 💰 Анализ игровой экономики

- Баланс доходов и расходов
- Логика системы кланов
- Справедливость дуэлей
- Защита от читерства

### 🔒 Безопасность

- Защита LocalStorage
- Валидация пользовательского ввода
- Безопасность API вызовов
- Защита от XSS атак

## Настройка уведомлений

### Email уведомления
1. В настройках CodeRabbit включите email уведомления
2. Выберите частоту: немедленно, ежедневно, еженедельно

### Slack интеграция (если используете)
1. В настройках CodeRabbit подключите Slack
2. Выберите канал для уведомлений
3. Настройте фильтры по важности

## Конфигурация .coderabbit.yaml

Основные настройки в файле `.coderabbit.yaml`:

```yaml
# Язык комментариев
language: ru

# Максимальное количество комментариев на PR
max_comments: 50

# Включить анализ безопасности
security: true

# Включить анализ производительности
performance: true

# Специальные настройки для игрового проекта
game_specific:
  mechanics_analysis: true
  balance_check: true
  performance_analysis: true
  data_security: true
```

## Работа с CodeRabbit

### Создание Pull Request

1. Создайте ветку для новой функции
2. Внесите изменения в код
3. Создайте Pull Request
4. CodeRabbit автоматически проанализирует код
5. Изучите комментарии и рекомендации
6. Внесите улучшения на основе предложений

### Типы комментариев CodeRabbit

- 🔍 **Анализ качества**: Предложения по улучшению кода
- 🚀 **Производительность**: Оптимизация скорости работы
- 🔒 **Безопасность**: Устранение уязвимостей
- 🎮 **Игровые механики**: Улучшение игрового процесса
- 📚 **Документация**: Предложения по комментированию

### Реагирование на комментарии

1. **Исправьте критические проблемы** сразу
2. **Обсудите спорные предложения** в комментариях
3. **Игнорируйте неподходящие** предложения
4. **Используйте эмодзи** для быстрой реакции

## Лучшие практики

### Для разработчиков

1. **Читайте комментарии внимательно** - CodeRabbit дает ценные советы
2. **Не игнорируйте предупреждения безопасности**
3. **Используйте предложения по оптимизации**
4. **Учитесь на рекомендациях** - это улучшает ваши навыки

### Для проекта

1. **Настройте CODEOWNERS** для правильного назначения ревьюеров
2. **Используйте labels** для категоризации PR
3. **Ведите changelog** изменений
4. **Документируйте архитектурные решения**

## Устранение проблем

### CodeRabbit не запускается

1. Проверьте права доступа GitHub App
2. Убедитесь, что workflow файл корректен
3. Проверьте логи в Actions tab

### Слишком много комментариев

1. Настройте `max_comments` в `.coderabbit.yaml`
2. Добавьте файлы в `exclude` секцию
3. Настройте фильтры по важности

### Неточные рекомендации

1. Настройте `learning.enabled: true` для обучения на вашем коде
2. Добавьте комментарии к коду для лучшего понимания
3. Используйте `@coderabbit` для уточнений
